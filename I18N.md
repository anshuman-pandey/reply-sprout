# Interface localization

Supported locales: `en`, `de`, `es`, `ja`, `zh-CN`, `zh-TW`. Hindi is not included. English is the source and fallback.

The picker uses native language names. An explicit choice is stored under `interface-language-v1`; browser language preferences are used otherwise. Regional German/Spanish/Japanese preferences map to their base locale. Traditional Chinese is selected for Hant/TW/HK/MO; other Chinese preferences select Simplified Chinese. Unsupported preferences fall back to English. Storage denial does not prevent switching for the current page.

Only explicitly marked interface text is translated. User-entered names, titles, snippets, URLs, testimonials, image contents and exported customer content remain unchanged. Switching languages does not reload the page or discard input. Catalog strings and interpolated values are inserted as text, never HTML. There are no remote translation requests or analytics.

Scope: app interface and bundled messages, not translated README editions. Native browser controls, permissions and browser-generated validation follow the browser/OS language. Unmapped server, browser and validation diagnostics remain readable in English; this is not a claim of complete diagnostic translation. Translation wording has not received independent native-speaker review.

## Verify

Install the existing product dependencies, then run `npm ci`, `npx playwright install chromium`, and `npm run test:i18n`. Python 3 is required by the isolated loopback fixture runner; server apps also need their normal Python requirements. `CHROMIUM_PATH` can select an installed Chromium executable.

The test checks all six choices, preference persistence, region negotiation, missing-message fallback, literal interpolation, preserved drafts/user text, narrow layouts and blocked storage. Existing workflow tests remain separate. Guide Stitch uses an explicit stubbed runtime for interface tests: it does not verify real toolbar capture or circumvent browser restrictions. Screen Parcel's language tests do not verify the real screen picker or microphone.

To add a message, update `messages.js` (under `static/` for server apps), mark the authored HTML with `data-i18n`, or bind a dynamic UI-only text node with `I18n.text`. Keep all five translation entries and numbered placeholders in sync. Never bind user-authored content as a translation key.
